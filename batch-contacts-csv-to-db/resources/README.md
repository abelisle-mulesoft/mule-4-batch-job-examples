# Resources

This folder contains supporting resources for setting up and running the Mule application:

- `Contact_Data_100.csv` and `Contact_Data_1m.csv.zip`: Sample contact datasets containing 100 and 1 million records, respectively. The 1-million-record dataset is provided as a ZIP archive.

  The smaller dataset is intended for unit and smoke testing, while the larger dataset is intended for demonstrating the execution of the Mule application with a high record volume. The data model is based on the Salesforce `Contact` object, and the fictitious data was generated using [Mockaroo](https://www.mockaroo.com).

- `Postgres-Contacts-Table.sql`: SQL script for creating the contacts table in the PostgreSQL database.

  The Mule application reads contact data from a CSV file and inserts the records into this table. The table uses the same data model as the sample contact data and includes an autogenerated `id` column, allowing the Mule application to be executed repeatedly without truncating or clearing the table between executions.
